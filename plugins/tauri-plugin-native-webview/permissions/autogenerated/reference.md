## Default Permission

Allows presenting a native web view popup via the `open` command, evaluating JS in it via the `send` command, updating its title/subtitle/message labels via `set_chrome`, and dismissing it via `close`.

#### This default permission set includes the following:

- `allow-open`
- `allow-send`
- `allow-set-chrome`
- `allow-close`
