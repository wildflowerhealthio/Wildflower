# Field

Labels a **single** control (input, select, or a read-only value) with an
eyebrow label above it. Tie the label to its control with `htmlFor` matching
the control's `id`; omit `htmlFor` when the field shows a read-only value
rather than an interactive control.

Pair with `FieldDescription` for a secondary helper line under the control.
For a set of related controls (a group of checkboxes or radios) reach for
`FieldGroup` instead.
