# Checkbox

A single labeled checkbox over a native `<input type="checkbox">`. Controlled
via `checked` + `onChange` (receives the next boolean). The `label` accepts
JSX, so scope names can be typeset in `<code>`. A `disabled` checkbox may omit
`onChange`.

Stack several inside a `FieldGroup` for a multi-select cluster (e.g. consent
scopes).
