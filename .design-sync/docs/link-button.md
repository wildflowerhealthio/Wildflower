# LinkButton

A `<button>` that reads as link text — underlined accent text, no box — for an
action inside prose or a compact surface (a status line, banner, tooltip, or
loader card) where a boxed `button-N` would overpower the copy. Use it for
actions that change state; use a real `<a>` for navigation. Props: `onClick`,
`children`, optional `className`.
